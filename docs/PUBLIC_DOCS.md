# Public Documentation Map

This page lists the recommended public reading order for visitors who want to understand, install, or validate this repository.

## Recommended Reading Order

1. [README.md](../README.md)
   Start here for the project purpose, repository status, included/excluded assets, and current limitations.

2. [quickstart.md](quickstart.md)
   Use this for clone, submodule, minimal install, and lightweight validation commands.

3. [reproducibility.md](reproducibility.md)
   Read this to understand what is reproducible now and what still requires external datasets, checkpoints, or model assets.

4. [dataset_reconstruction.md](dataset_reconstruction.md)
   Use this when preparing external dataset roots, manifests, selected audio exports, and validation flow.

5. [patch_application_plan.md](patch_application_plan.md)
   Read this before working with preserved third-party patches. The current workflow is dry-run only.

6. [license_notes.md](license_notes.md)
   Review licensing scope, third-party caveats, and why upstream terms still matter.

7. [ci_status.md](ci_status.md)
   Check what CI validates and which heavy tests remain intentionally excluded.

# Manifest Policy

Datasets are intentionally not committed to this repository.

This directory should contain only lightweight metadata such as:

- Schemas
- Tiny example manifests
- Path conventions
- Download or reconstruction instructions
- Notes on dataset splits or expected external assets

Do not commit:

- Raw audio
- Copied audio subsets
- Full JSONL or JSON datasets
- Checkpoints
- Result dumps
- Embedding caches
- Large generated manifests

Future dataset manifests should use relative paths where possible and should not require committing audio into Git.
